# 01 常用命令速查

本文档按使用场景整理 Git 常用命令，每个场景给出命令和一句话说明。

## 一、仓库初始化与克隆

| 命令 | 说明 |
| --- | --- |
| `git init` | 在当前目录初始化一个新的本地仓库 |
| `git clone <地址>` | 把远程仓库完整复制到本地，并自动关联远程库 |
| `git remote -v` | 查看当前仓库关联的远程库地址 |

克隆得到的仓库不需要再执行 `git remote add`，因为 `clone` 已经把远程库命名为 `origin`。

## 二、日常提交

| 命令 | 说明 |
| --- | --- |
| `git status` | 查看工作区与暂存区状态 |
| `git add <文件>` | 把指定文件放入暂存区 |
| `git add .` | 把当前目录所有改动放入暂存区 |
| `git commit -m "说明"` | 把暂存区内容提交为一个版本 |
| `git log --oneline` | 单行显示提交历史 |
| `git diff` | 查看尚未暂存的改动内容 |

## 三、远程同步

| 命令 | 说明 |
| --- | --- |
| `git push -u origin main` | 首次推送并建立本地与远程分支的追踪关系 |
| `git push` | 之后的推送可省略参数 |
| `git pull` | 拉取远程更新并合并到当前分支 |
| `git fetch` | 只获取远程更新，不自动合并 |

## 四、撤销与回退

| 命令 | 说明 |
| --- | --- |
| `git checkout -- <文件>` | 丢弃工作区中未暂存的修改 |
| `git reset HEAD <文件>` | 把文件从暂存区撤出 |
| `git reset --soft HEAD~1` | 撤销最近一次提交，改动保留在暂存区 |
| `git revert <提交号>` | 生成一个新提交来抵消指定提交，适合已推送的历史 |

## 五、查看帮助

```bash
git help <命令>
git <命令> -h
```

遇到不熟悉的命令时，优先查看官方帮助，比搜索引擎更快也更准确。
