# 03 贡献指南

欢迎通过 Issue 或分支提交参与本项目。为了减少沟通成本，请遵循下面的约定。

## 一、通过 Issue 反馈

在仓库的 Issues 页面点击 New issue，标题尽量写清楚问题范围，正文包括：

- 你做了什么操作（附完整命令）
- 期望的结果
- 实际的结果（附报错信息或截图）

## 二、分支命名

从 `main` 切出分支，命名采用"类型/简短描述"的形式：

| 前缀 | 用途 | 示例 |
| --- | --- | --- |
| `feature/` | 新增内容或功能 | `feature/rebase-guide` |
| `fix/` | 修正错误 | `fix/broken-link` |
| `docs/` | 仅修改文档 | `docs/fix-typo` |

## 三、提交信息

提交信息使用"类型: 说明"的格式，一句话说明这次提交做了什么：

```
docs: 补充 rebase 命令说明
fix: 修正分支合并示例中的错误命令
```

## 四、合并流程

1. 在分支上完成修改并提交
2. 确认 `git status` 没有遗留未提交内容
3. 切回 `main` 执行 `git merge <分支名>`
4. 若出现冲突，按冲突标记逐处解决后再 `git add` 与 `git commit`
5. 推送后删除已合并的临时分支
