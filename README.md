# gitclonelearn09 —— Git 学习与实践示例仓库

本项目是一个面向 Git 初学者的开源学习仓库。仓库把日常开发中最常用的 Git 操作按使用场景整理成文档，并给出可以直接在本地复现的命令序列，帮助初学者弄清"每条命令到底做了什么"，而不只是背命令。

## 项目特点

- 场景化整理：克隆、分支、合并、推送等操作按真实开发流程组织，而不是罗列命令表
- 可复现：每个知识点都附带完整命令序列，按顺序执行即可验证结果
- 中文文档：专业术语后附英文原词，降低初学者的阅读门槛
- 开源协作：采用 MIT 许可证发布，欢迎通过 Issue 提出建议或参与改进

## 快速开始

将仓库克隆到本地：

```bash
git clone git@github.com:c-loverrrr/gitclonelearn09.git
cd gitclonelearn09
```

查看仓库状态与提交记录：

```bash
git status
git log --oneline --graph
```

## 贡献方式

1. 通过 Issue 描述你发现的问题或希望补充的内容
2. 从 `main` 分支切出 `feature/xxx` 分支进行修改
3. 提交时使用清晰的提交信息，例如 `docs: 补充 rebase 命令说明`
4. 合并前确认没有未解决的冲突

详细规范见 [贡献指南](docs/03-贡献指南.md)。
